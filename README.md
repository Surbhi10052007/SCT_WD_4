# To Do Web App

A modern and responsive To Do List web application built using HTML, CSS, and JavaScript.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Tasks saved using localStorage
- Responsive design for mobile and desktop
- Clean and modern UI

## Technologies Used
- HTML
- CSS
- JavaScript
